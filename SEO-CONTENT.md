## Key SEO Principles Applied

1. **Title tags:** 29-52 characters (within 60 limit), primary keyword first, brand at end
2. **Meta descriptions:** 150-158 characters, action-oriented, include location (Hamilton/Waikato)
3. **Local SEO:** Consistent use of "Hamilton" and "Waikato" for geographic targeting
4. **Keywords:** IT support, managed services, cloud technology, server security
5. **Call to action:** "Get expert help today", "Contact us today", etc.
